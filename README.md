# Campus Event Hub — ISE-2

## Project Objective
Campus Event Hub is a simple website where students can explore campus events and register their interest.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub
- Jenkins

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Browse the sample campus events.
4. Use the category filters to find events.
5. Click Register Interest to try the registration button.

## Git and GitHub Workflow
1. Create a GitHub repository.
2. Upload the project files.
3. Make meaningful changes to the website.
4. Commit and push each change.
5. Review the commit history on GitHub.

## Jenkins Integration
The Jenkinsfile defines a pipeline to check out the repository and validate required website files and content.

1. Open Jenkins.
2. Create a new Pipeline job.
3. Select Pipeline script from SCM.
4. Choose Git and enter this repository URL:
   https://github.com/sarthak262006-design/campus-event-hub.git
5. Set the branch to */main.
6. Set Script Path to Jenkinsfile.
7. Save and click Build Now.
8. Check Console Output for the build result.

## Required Evidence
- Website screenshot
- GitHub repository screenshot
- At least five meaningful commits
- Jenkins pipeline and build-result screenshots

  ## Website Features

- Displays campus events in organized cards.
- Allows students to search for events.
- Filters events by category.
- Shows event dates and venues.
- Includes a Register Interest button.
- Provides a responsive layout for mobile and desktop screens.

## How to Use

1. Open index.html in a web browser.
2. Browse the available sample events.
3. Search for an event or select a category.
4. Click Register Interest to mark your interest.
5. Click Interested again to undo your selection.
